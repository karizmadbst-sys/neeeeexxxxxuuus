- Never group all icons into one image or fixed panel.

### 2. Backpack Inventory
When the player opens the backpack, display a visual inventory made entirely of icons.

Show separate item icons for:
- Every weapon the player owns.
- Ammunition for each weapon.
- Health and medkits.
- Armor and helmets.
- Other collected items.

Display item quantities using small visual number indicators, not descriptive text.

### 3. Drag and Drop Trash System
- Add a visible trash-bin icon inside the backpack.
- Allow the player to drag any unwanted weapon or item onto the trash bin to remove it.
- Show a clear visual effect when an item is successfully removed.
- Update the inventory immediately.
- Update weapon slots and ammunition correctly.
- Do not allow accidental deletion without a clear drag-and-drop action.

### 4. Visual Design
- Use real high-quality PNG or SVG icons with transparent backgrounds.

- Do not replace icons with text, letters, emojis, or plain rectangles.
- Make icons clear, attractive, and easy to tap on mobile.
- Support both Android and PC.
- Make drag-and-drop work with touch input and mouse input.

### 5. Important Requirements
- Keep all existing game features and systems working.

### 6. Fully Functional HUD Editor Buttons

- **SAVE:** Save the current icon positions, sizes, and transparency permanently. The saved layout must remain unchanged after closing and reopening the game.
- **RESTART / RESET:** Restore all HUD icons to their original default positions and sizes. Ask for confirmation before resetting.
